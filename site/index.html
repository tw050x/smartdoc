Shortlist Dock

Review your CV with your own AI. Shortlist Dock shows your CV in an app on your computer: the AI marks up the text and suggests changes, you accept, reject or answer each one, and it writes the next draft from your decisions.

Claude Desktop

Install it as an extension.

  1. Download for Claude Desktop
  2. Open the downloaded file. Claude Desktop shows what it installs; choose Install.
  3. Start a new chat and ask Claude to review your CV. The Shortlist Dock app opens when Claude needs it.

Claude Code

Add it with one command.

  1. Run this in a terminal: 
    claude mcp add --scope user shortlist-dock -- npx -y shortlist-dock
  2. Start a new Claude Code session and ask Claude to review your CV. The Shortlist Dock app opens when Claude needs it.

Needs Node.js 18 or later. Other AI apps that run MCP servers can use the same command: npx -y shortlist-dock.

Good to know

  • Runs on macOS (Apple silicon or Intel). Windows is planned.
  • The first time it starts, it downloads the app from the project’s GitHub releases and checks it against the release’s checksums.
  • Your CV stays on your computer. Your AI only sees what it reads through Shortlist Dock, and the app only accepts connections from your own computer.
  • Free, with no account. The AI is your own, under your own subscription.
