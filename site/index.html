Your agent

Your agent suggests changes to your document, and you decide on every one: accept, reject or edit it. Then your agent writes the next draft.

Step 1 · Open

Open your CV in SmartDoc

Drop the PDF on SmartDoc, or ask your agent to open it. It shows the document exactly as it is, page for page.

Open the focus menu, write what the review is for, and copy the prompt for your agent.

Step 3 · Review

Your agent reviews it

Paste the prompt into your agent. It reads the CV and adds suggestions as it goes, each beside the text it’s about.

Step 4 · Decide

Decide on each suggestion

Choose a rewrite, accept a change, or edit it yourself. Nothing changes until you say so.

Step 4 · Decide

Answer what only you know

Step 5 · Redraft

Get the next draft

Copy one prompt. Your agent writes Draft 1 from your decisions, and it opens in SmartDoc by itself.

Step 6 · Highlight

Ask what matters

Switch to Review and highlight and say what you’re looking for. Your agent picks out the key information, including what’s missing.

Step 7 · Tailor

A version for each job

Right-click a draft and make a variation for one job. Your agent tailors it, and the original stays as it is.

Free and open source

SmartDoc is free. Completely.

No account, no trial, no paid plan. SmartDoc is released under the MIT licence, which means it stays free: once it’s out, nobody can take that back.

It’s one of the most common licences for free software, written at the Massachusetts Institute of Technology. In plain terms:

    At home or at work, for as long as you like. You never pay, and you never need permission.

  • See how it works

    All of SmartDoc’s code is public. Anyone can read it, copy it, or change it to suit them.

  • Just one condition

    Anyone who shares a copy keeps the licence with it. It comes as it is, without a guarantee.

Install

Install it, then add it to your agent.

Download SmartDoc (or for an Intel Mac), open the file and drag SmartDoc into your Applications folder. SmartDoc must be in Applications: that’s where your agent finds it. (With Node.js, npx @smartdoc/cli install puts it there for you.) Then connect it to your agent: Claude Desktop, Claude Code, or any agent that runs MCP servers. It opens by itself whenever your agent needs it.

Claude Desktop

SmartDoc adds itself.

  1. Open SmartDoc and click Ready, at the top right.
  2. Choose Add to Claude Desktop.
  3. Quit Claude Desktop and open it again. Then start a new chat and ask Claude to review your document.

Or add it yourself: in Claude Desktop, open Settings → Developer → Edit Config, and add the entry from the Other agents tab.

Claude Code

Add it with one command.

  1. Run this in a terminal: 
    claude mcp add --scope user smartdoc -e ELECTRON_RUN_AS_NODE=1 -- /Applications/SmartDoc.app/Contents/MacOS/SmartDoc /Applications/SmartDoc.app/Contents/Resources/cli/mcp.js
  2. Start a new Claude Code session and ask Claude to review your document.

Or, with Node.js, run npx @smartdoc/cli setup, which sets up Claude Code and Claude Desktop for you.

Other agents

Any agent that runs MCP servers can use SmartDoc.

  1. Add SmartDoc as an MCP server. Most agents take a config entry like this: 
    {
  "mcpServers": {
    "smartdoc": {
      "command": "/Applications/SmartDoc.app/Contents/MacOS/SmartDoc",
      "args": [
        "/Applications/SmartDoc.app/Contents/Resources/cli/mcp.js"
      ],
      "env": {
        "ELECTRON_RUN_AS_NODE": "1"
      }
    }
  }
}
  2. Restart your agent and ask it to review your document.

SmartDoc runs its connection itself, so there’s nothing else to install.

Good to know

Your files, your agent.

  • Bring your own agent

    SmartDoc works with the agent you already use. No new account, no new subscription: just a better way to work on documents together.

  • You have the final say

    Your agent suggests; you decide. Nothing in your document changes until you’ve said yes.

  • Nothing gets lost

    Every draft is kept, and every variation too. Step back to any version whenever you like.

  • One document, many versions

    Tailor a variation for each job or reader, and keep the original just as it was.

  • Point at anything

    Mark any line to rewrite, question or keep, and your agent answers each one.

  • See what matters

    Ask your agent what a reader would look for, and see it highlighted on the page.

  • There when you need it

    Your agent opens SmartDoc by itself, right where you left off.

  • Free to use

    No sign-up and no plan to choose. SmartDoc is free.

  • Open source

    Every line of SmartDoc is on GitHub, for anyone to read.
